## 遗留风险

- `node-pty` 是 native dependency，不同系统可能需要编译工具链。
- Skills 安装实际成功取决于 `npx skills`、网络和本机目标 CLI 环境。
- 当前 `/skills` 页面只开放 `skills_install` 受限 profile，`project_shell` 作为后端可复用底座暂未暴露到页面。
