## 代码审查记录

本轮人工审查重点：

- API 语义：详情、extraction、chunks、search、reprocess、patch、delete route 与前端 API client 对齐。
- 检索语义：ready 且 enabled 的 chunks 参与 FTS；禁用后不再命中，恢复后重新命中。
- 引用上下文：会话库引用优先使用知识库 chunks/extraction，并输出 `citation_key: knowledge:<sourceId>`。
- UI 数据真实性：移除 `FALLBACK_STATS`、`FALLBACK_ROWS`、固定页数、固定时间、固定引用数和旧项目名。
- 响应式：移动端使用 `.knowledge-mobile-list`，桌面表格在小屏隐藏。
- 子代理 review 未派发：当前子代理工具要求必须由用户明确要求才能使用，且接口不提供项目要求的 `model` 与 `reasoning_effort` 字段；本轮改为主会话结构化审查。

审查结论：未发现阻止 Phase 1 合入的问题。剩余风险是前端生产包仍有大 chunk 提示，属于既有打包体积优化项，不影响本次 Phase 1 验收。
