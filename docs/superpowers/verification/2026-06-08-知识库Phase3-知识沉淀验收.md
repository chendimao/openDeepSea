## 验收结果

1. `POST /api/sessions/:sessionId/knowledge-notes` 可保存 session message 为 `session_note`，返回 `201`。
2. 同 session 同正文重复保存返回已有 source，`deduplicated=true`，返回 `200`。
3. 跨 session message 被拒绝，返回 `400`；缺失 session 返回 `404`。
4. 笔记写入现有 `knowledge_sources`、`knowledge_extractions`、`knowledge_chunks`，并可通过知识搜索命中。
5. metadata deterministic 提取覆盖 `decisions`、`constraints`、`risks`、`learnings`。
6. Session UI 的 user/assistant 消息可显示 `保存为知识` 次级操作，保存中禁用当前消息按钮。
7. 保存成功后刷新 `knowledge-sources` 与 `knowledge-search` query，并区分新建与重复 toast。

## 风险与后续

- 本阶段只做同 session 同内容 hash 去重，语义重复不处理。
- metadata 提取为关键词规则，隐含决策可能漏识别。
- 浏览器 smoke 未点击真实保存按钮，避免污染当前本地数据库；保存行为由后端 API 测试和前端 API/mutation 接线测试覆盖。
