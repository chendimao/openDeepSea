## 代码审查

审查清单：

- Search 不泄露 storage paths：通过。Agent RAG search/list/source summary 仅返回 source id、chunk id、title、type、summary、tags、chunk count、citation key 等安全字段。
- URL import 不抓网络：通过。URL 导入只校验 http/https URL；没有内容时创建 `stale` metadata-only source，并标记 `requires_fetch: true`，不执行 fetch。
- Workspace import 拒绝 absolute/traversal/ignored/binary/oversized：已修复并覆盖测试。导入复用 `readWorkspaceFilePreview()` 的路径、ignored、binary 校验，并新增 `preview.truncated` 到 `WORKSPACE_FILE_TOO_LARGE` failure。
- `metadataPatch` 不能覆盖任意 metadata：通过。route schema 使用 `.strict()`，service 层只允许 `key_points`、`decisions`、`constraints`、`risks`、`learnings`。
- Agent task/workflow/collaboration 注入知识 prompt，internal message 不注入：通过。`shouldInjectKnowledgeAgentToolPrompt()` 仅排除 `internalMessage`，task/workflow/collaboration 均可注入；对应测试通过。
- Hybrid search 保持 project/room/status/sourceType/enabled chunk filter：通过。keyword 和 vector 分支均带 project/room/status/sourceType 过滤，vector 分支跳过 disabled chunk；对应测试通过。
- UI 高密度、无嵌套卡片、桌面/移动无明显重叠：已修复移动端标题挤压；最终截图目检通过。

- workspace oversized 文本会被截断后导入，已改为 failure 并新增测试。
