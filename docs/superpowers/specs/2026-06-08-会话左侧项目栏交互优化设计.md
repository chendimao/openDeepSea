# 会话左侧项目栏交互优化设计

## 背景

会话工作区左侧栏已经改为项目会话树，但现有实现仍有几个干扰点：项目右侧操作按钮常驻、项目操作菜单包含未实现占位项、项目默认全部展开、会话行缺少直接置顶入口，项目排序能力也没有在会话页左侧栏暴露。

本次设计基于 A 方案：保持项目会话树结构，做最小充分增强，并参考用户提供的紧凑项目列表截图调整字号、行距、缩进和当前会话高亮。

## 目标

1. 当前项目默认展开，其他项目默认折叠。
2. 项目名称左侧不显示折叠三角或 chevron，只保留文件夹图标。
3. 项目右侧更多菜单按钮只在项目行 hover、focus-within 或菜单打开时显示。
4. 项目更多菜单只保留「编辑名称」和「移除」。
5. 会话行 hover 或 focus 时，最左侧显示置顶按钮；已置顶会话的置顶按钮常显。
6. 项目之间可通过拖拽调整顺序，并复用现有 `sort_order` 能力。
7. 侧栏视觉更接近参考图：轻量项目行、紧凑会话行、固定时间列、浅灰圆角当前态。

## 非目标

1. 不重做会话工作区整体布局。
2. 不引入项目文件库、项目设置等新入口。
3. 不增加会话归档、删除、重命名等会话行菜单。
4. 不改变后端项目排序数据模型。
5. 不把项目置顶能力放进本次会话页项目菜单；本次菜单只保留编辑名称和移除。

## 交互设计

### 项目展开状态

- 初始状态下，当前会话所在项目展开。
- 非当前项目默认折叠。
- 搜索状态下，匹配项目或匹配会话所在项目自动展开。
- 用户点击项目行可切换展开和折叠。
- 项目行保留 `aria-expanded`，但视觉上不显示折叠图标。

### 项目行操作

- 项目行左侧显示文件夹图标和项目名称。
- 项目名称左侧不显示 chevron。
- 项目行右侧的更多按钮默认隐藏。
- 更多按钮在项目行 hover、focus-within 或菜单打开时显示。
- 菜单项只包含：
  - 编辑名称
  - 移除
- 菜单项必须是真实动作或明确接入现有动作，不再渲染 disabled 占位功能。

### 会话行置顶

- 会话行最左侧预留置顶按钮位置，避免 hover 出现按钮时文字跳动。
- 未置顶会话：置顶按钮默认透明，hover 或键盘 focus 时显示。
- 已置顶会话：置顶按钮常显，并使用轻量选中态。
- 点击置顶按钮只切换置顶状态，不触发打开会话。
- 点击会话行主体仍打开会话。

### 项目拖拽排序

- 项目行支持拖拽。
- 拖拽排序只在同一排序层内生效，沿用现有 `pinned_at` 分层约束。
- 拖拽目标行显示轻量 drop target 状态。
- 排序提交使用现有 `api.reorderProjects({ ids, pinned })`。
- 排序成功后刷新 `projectSwitcher` 所依赖的数据；若失败，保留原顺序并显示错误提示。

## 视觉设计

### 布局密度

- 左栏宽度继续沿用现有会话页宽度。
- 项目行高度约 32px 到 34px。
- 普通会话行高度约 30px 到 32px。
- 当前会话行高度约 34px 到 36px，并使用浅灰圆角背景。
- 项目标题到会话列表之间保留 8px 到 12px 间距。
- 会话列表相对项目名有明确缩进，形成参考图中的层级关系。

### 字号

- 侧栏标题「项目」约 18px 到 20px。
- 项目名称约 17px 到 18px。
- 会话标题约 15px 到 16px。
- 时间文本约 14px 到 15px。
- 实际落地按当前侧栏尺寸换算，不直接照搬截图放大像素。

### 文本和时间

- 会话标题单行显示，超出后省略。
- 时间列固定在右侧，不能被标题挤压。
- 当前会话使用浅灰圆角高亮，不使用大面积边框或卡片阴影。
- 普通 hover 态只做轻微背景变化。

## 数据和接口

### 可复用能力

- 项目排序字段已经存在：`projects.pinned_at`、`projects.sort_order`。
- 项目排序接口已经存在：`PUT /projects/reorder`。
- 项目更新接口已经存在：`PATCH /projects/:id`，可用于编辑名称。
- 项目删除接口已经存在：`DELETE /projects/:id`。
- 会话模型已有 `pinned_at` 字段，活跃会话摘要也已包含该字段。

### 需要补齐的能力

当前 `PATCH /sessions/:sessionId` 未暴露 `pinned_at`。为实现会话行置顶，本次采用最小改动：扩展现有 session update schema，允许 `pinned_at: number | null`。前端置顶时传入 `Date.now()`，取消置顶时传入 `null`。

更新成功后沿用现有 `broadcastActiveSessionUpsert`，让左侧活跃会话列表实时刷新排序和置顶状态。

## 组件边界

主要修改范围：

- `packages/frontend/src/session-ui/SessionShellView.tsx`
  - 调整项目默认展开状态。
  - 去掉项目名前折叠图标。
  - 精简项目菜单。
  - 接入项目拖拽排序。
  - 增加会话置顶按钮。
- `packages/frontend/src/session-ui/session-os.css`
  - 调整字号、行高、缩进、hover 显隐和当前态。
- `packages/frontend/src/pages/SessionWorkspacePage.tsx`
  - 在页面层接入项目排序、项目编辑、项目移除、会话置顶 mutation，并负责刷新或更新当前 payload。
- `packages/frontend/src/lib/api.ts`
  - 扩展 `updateSession` 入参支持 `pinned_at`。
- `packages/backend/src/session.routes.ts`
  - 扩展 session update schema 支持 `pinned_at`。

## 验证

至少覆盖以下用例：

1. 当前项目默认展开，其他项目默认折叠。
2. 项目名称左侧不渲染折叠图标。
3. 项目菜单只渲染「编辑名称」和「移除」。
4. 项目更多按钮默认隐藏，并在 hover/focus/menu open 状态可见。
5. 会话置顶按钮默认隐藏，hover/focus 或已置顶时可见。
6. 点击会话置顶按钮不会触发打开会话。
7. 项目拖拽排序调用 `api.reorderProjects`，并保持同层排序。
8. `PATCH /sessions/:sessionId` 支持更新 `pinned_at`，并广播活跃会话摘要。
9. 视觉验证：侧栏截图中会话文字、时间列、当前高亮无重叠。

## 验收标准

1. 打开会话页时，当前项目展开，其他项目折叠。
2. 项目名前没有折叠三角或 chevron。
3. 项目更多按钮默认不可见，移动到项目行时显示。
4. 项目菜单只有编辑名称和移除。
5. 移动到会话行时，最左侧出现置顶按钮；置顶会话能取消置顶。
6. 拖拽项目后刷新页面仍保持新顺序。
7. 侧栏整体字号、行距和当前会话高亮接近参考图，并保持可读、无溢出。
