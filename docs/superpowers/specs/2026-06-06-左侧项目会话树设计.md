# 左侧项目会话树设计

## 背景

Stitch 参考稿：

- 项目：`Deepsea Command Center Rebuild`
- 画面：`深海指挥中心 - 极简状态栏路径版 (4:3)`
- Screen：`projects/2494186768077294944/screens/93e3e05fe3e74bbd9647d9674e3016dd`

当前会话工作区左侧栏已经从“会话历史”调整为“活跃会话”，但现有实现仍是平铺卡片列表。目标稿的左侧栏更接近项目路径树：顶部保留全局动作，中部按项目分组展示会话，底部保留聊天入口。该结构更符合多项目、多会话同步开发场景。

## 目标

将左侧栏定义为“项目会话导航树”：

1. 展示所有项目，不只展示有活跃会话的项目。
2. 每个项目节点下展示该项目当前活跃会话。
3. 当前项目和有活跃会话的项目默认展开。
4. 当前会话用轻量高亮表达，不使用大卡片。
5. 搜索同时匹配项目名、项目路径和会话标题。
6. 空项目保留入口，并显示轻量空态。

## 非目标

1. 不重新引入“会话历史”作为左侧主语义。
2. 不在第一版混入已归档或已关闭会话。
3. 不修改后端 WebSocket 订阅模型。
4. 不重做顶部全局导航、右侧 inspector 或中间 transcript。
5. 不完整复制 Stitch 的玻璃拟态材质，仅还原信息架构、密度和路径感。

## 信息架构

左侧栏结构：

```text
新建会话
搜索

项目
  openDeepSea
    当前活跃会话标题                 3 小时
    另一个活跃会话                   刚刚
    展开显示

  Project B
    暂无活跃会话

聊天
  暂无聊天
```

项目节点包含：

- 项目图标
- 项目名称
- 活跃会话数量
- 展开/收起控件

会话行包含：

- 会话标题
- 相对更新时间
- 当前态高亮
- 运行中、阻塞、失败等最小状态信号
- 未读数和置顶状态的紧凑标记

## 数据来源

第一版只使用现有 payload：

- `payload.projectSwitcher.projects`：所有项目列表、项目路径、当前项目标记。
- `payload.activeSessions`：跨项目活跃会话列表。
- `payload.activeSession.session`：当前聚焦会话。

前端按 `project_id` 将活跃会话分组到项目下。找不到项目的活跃会话不应丢失，放入“其他项目”兜底组。

## 交互

1. 点击项目节点：展开或收起项目。
2. 点击会话行：调用现有 `onOpenSession(projectId, sessionId)`。
3. 点击“新建会话”：调用现有 `/new` 命令。
4. 搜索为空时：
   - 当前项目默认展开。
   - 有活跃会话的项目默认展开。
   - 无活跃会话的非当前项目可保持收起。
5. 搜索非空时：
   - 显示匹配项目或匹配会话所在项目。
   - 匹配项目自动展开。

## 视觉规则

1. 左栏宽度继续使用当前 `320px` 列宽。
2. 采用浅色半透明背景和细边界，保持当前 Deepsea shell 体系。
3. 会话行使用单行紧凑布局，避免现有卡片式 provider/model footer。
4. 当前会话使用淡白背景、细边框和文本权重表达。
5. 运行中状态使用小点或短文本，不使用大色块。
6. 文字必须单行截断，不能挤压右侧时间。
7. 控件保持键盘可聚焦，项目展开按钮有 `aria-expanded`。

4. 空项目显示“暂无活跃会话”或收起状态。
