# 工作流计划显式串行模式保留 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `WorkflowPlanJson` 归一化保留显式 `mode: serial`，避免 Coordinator 或结构化计划声明的串行任务被错误降级为并行任务。

**Architecture:** `depends_on` 仍然是强串行信号，带依赖任务即使声明 `parallel` 也会归一化为 `serial`；无依赖任务只有在显式声明 `serial` 时才保留串行，否则默认 `parallel`。这保持安全侧偏保守，同时支持上一阶段 execute fallback 对显式 serial 的运行时保护。

**Tech Stack:** Node.js、TypeScript、node:test。

```ts

```

新增 helper：

```ts
function normalizeTaskMode(mode: WorkflowPlanTaskMode | undefined, dependsOn: string[]): WorkflowPlanTaskMode {
  if (dependsOn.length > 0) return 'serial';
  if (mode === 'serial') return 'serial';
  return 'parallel';
}
```

保留 `deriveMode()` 或删除均可，但不得让显式 `serial` 丢失。
