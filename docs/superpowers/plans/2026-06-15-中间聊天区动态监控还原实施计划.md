> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 只改中间聊天区域，将 workflow 与 agent run 消息的样式、布局、排版高精度贴近 Stitch「深海指挥中心 - 动态监控增强版 (4:3)」。

**Tech Stack:** React 18、TypeScript、Vite、Node test runner、Playwright CLI、CSS。
