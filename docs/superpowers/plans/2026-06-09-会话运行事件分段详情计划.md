# 会话运行事件分段详情 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让会话页智能体运行输出按真实工具/计划/文件事件断开，并在文本段尾部提供弹窗详情入口。

**Architecture:** 复用现有 `SessionAgentEvent` 数据流，不改后端采集。`buildSessionRunTranscriptItems` 负责把 answer 文本和可展示事件分组为 transcript item；`SessionRunTimeline` 负责渲染文本段尾部详情按钮和弹窗。

**Tech Stack:** React 18、TypeScript、Vite、lucide-react、Node test runner。

---
