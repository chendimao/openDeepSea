# 会话消息复制与知识保存 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在项目会话页为所有消息新增一键复制，并把智能体回复的“保存为知识”放到“预览 / 源码”旁边的同一工具组中。

**Architecture:** 本次只改前端会话 UI 和既有知识保存调用链。`SessionShellView.tsx` 负责消息/run 操作模型、复制状态和保存 action key；`SessionMessageBubble.tsx` 负责把普通消息头工具组合并到 `MarkdownDisplaySwitch` 旁；`SessionWorkspacePage.tsx` 负责把 message/run 两种保存输入转成现有 `createSessionKnowledgeNote` API payload。

**Tech Stack:** React 18、TypeScript、Vite、lucide-react、sonner、Node.js `node --import tsx --test`、npm workspaces。

---

const [copiedActionKey, setCopiedActionKey] = useState<string | null>(null);
const copyTranscriptText = async (content: string, key: string) => {
  try {
    await navigator.clipboard.writeText(content);
    setCopiedActionKey(key);
    window.setTimeout(() => setCopiedActionKey((current) => current === key ? null : current), 1200);
  } catch {
    setCopiedActionKey(null);
    toast.error('复制失败，请检查浏览器剪贴板权限');
  }
};
