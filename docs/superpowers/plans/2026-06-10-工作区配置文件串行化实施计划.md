# 工作区配置文件串行化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 并行 implementation 调度必须把不符合 `*.config.*` 命名的根级工作区/CI 配置写入视为高风险串行任务。

**Architecture:** 在现有 `scopePathRequiresSerial()` 中补充精确 basename 集合，例如 `turbo.json`、`pnpm-workspace.yaml`、`nx.json` 和 CI 配置文件。并行调度入口仍复用 `scopeWritesRequireSerial()`，无需新增状态。

**Tech Stack:** Node.js test runner、TypeScript、graph workflow execute node。
