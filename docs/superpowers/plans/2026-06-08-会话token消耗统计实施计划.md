# 会话 Token 消耗统计 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 状态栏显示当前会话累计 token 消耗，并把每次运行观测到的 token usage 写入 `session_token_usage` 表，供后续历史报表使用。

**Architecture:** 后端在 ACP chunk 进入 session runtime 时标准化抽取 provider usage，写入 `session_token_usage` 作为 run 级 usage snapshot；workspace payload 和实时 WebSocket 事件都从该表聚合当前会话累计值。前端只消费 `bottomStatus.tokenUsage`，不自行解析 provider 原始事件。

**Tech Stack:** Node.js、TypeScript、better-sqlite3、Express/WebSocket、React 18、Vite、node:test。
