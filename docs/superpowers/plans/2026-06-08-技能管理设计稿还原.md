# 技能管理设计稿还原实施计划

**目标：** 将 `/skills` 页面高精度还原为 Stitch 设计稿「深海指挥中心 - 技能管理 (极致高密度 16:9 还原版)」。

**边界：**
- 仅覆盖技能管理页及必要的 route 级壳层样式。
- 保留现有平台 skills API 查询、刷新和筛选能力。
- 数据不足时使用假数据补齐市场信息、作者、分类、依赖、活动记录等展示字段。
- 不改后端接口，不删除用户已有未提交改动。

**风险：**
- 目标 Stitch 截图下载尺寸为缩略图，主要以 HTML 结构和设计系统 token 做还原依据。
- 当前全局 `index.css` 已有未提交改动，追加样式时需避免覆盖无关页面。

**验证方式：**
- `npm run build`
- 启动前端开发服务并用 Playwright 截图检查 `/skills`
- 人工对照 Stitch HTML 的三栏布局、64px 顶栏、256px 左栏、320px 右栏、列表密度、颜色和控件状态
