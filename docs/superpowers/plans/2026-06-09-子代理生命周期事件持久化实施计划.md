# 子代理生命周期事件持久化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 OpenDeepSea 原生 `subagent_execution` 的 child run 启动、完成和失败事件写入 `task_events` 持久事实源，并避免 `/task-events` 查询重复合成同一批子代理事件。

**Architecture:** 后端继续保留 `agent_run_links` 作为父子 run 关系源，但 native subagent lifecycle 由 `task-actions.ts` 在 child run 创建和结束时写入 runtime 层 `task_events`。`routes.ts` 只在旧数据没有持久化 `subagent_*` runtime events 时，才从 `agent_run_links` 合成兼容事件。

**Tech Stack:** Node.js、TypeScript、SQLite/better-sqlite3、node:test、Express route tests。

```ts
function recordSubagentRunLifecycleEvent(input: {
  roomId: string;
  taskId: string;
  parentRunId: string;
  link: AgentRunLink;
  childRun: AgentRun | undefined;
  result?: TaskActionAgentResult;
  error?: string | null;
}): TaskEvent {
  const event = createSubagentRunTaskEvent(input.link, input.childRun, {
    result: input.result,
    error: input.error,
  });
  return taskEventRepo.create({
    task_id: input.taskId,
    room_id: input.roomId,
    type: 'runtime_event',
    layer: 'runtime',
    source_run_id: input.parentRunId,
    payload: event.payload,
  });
}
```

同时让 `createSubagentRunTaskEvent()` 接收可选 result/error，并把 `result_summary`、`error`、`started_at`、`completed_at` 放入 payload。

- [x] **Step 3: 实现 route 去重**

在 `routes.ts` 中新增 helper：

```ts
function hasPersistedSubagentRuntimeEvents(events: TaskEvent[]): boolean {
  return events.some((event) =>
    event.type === 'runtime_event' &&
    event.layer === 'runtime' &&
    typeof event.payload.timeline_type === 'string' &&
    event.payload.timeline_type.startsWith('subagent_') &&
    typeof event.payload.child_run_id === 'string' &&
    event.payload.child_run_id.trim().length > 0
  );
}
```

然后把 projection 条件改为：

```ts
  const projectedEvents = taskId && (!layer || layer === 'runtime') && !hasPersistedSubagentRuntimeEvents(repoEvents)
    ? createSubagentRunTaskEvents(taskId)
    : [];
```
