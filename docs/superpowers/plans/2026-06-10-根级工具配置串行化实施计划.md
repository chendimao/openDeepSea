# 根级工具配置串行化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 并行 implementation 调度必须把常见根级工具配置写入视为高风险串行任务，避免与其他子任务并行写入。

**Architecture:** 复用 `scopeWritesRequireSerial()` / `scopePathRequiresSerial()` 的现有准入点，只扩展根级配置文件名判断。调度层仍通过已有 parallel batch 和 next child 选择逻辑自然串行化，不新增状态字段。

**Tech Stack:** Node.js test runner、TypeScript、graph workflow execute node。
