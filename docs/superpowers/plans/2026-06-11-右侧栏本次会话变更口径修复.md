# 右侧栏本次会话变更口径修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 Session Workspace 右侧栏“本次会话变更”没有按当前会话生效的问题，使其只统计当前 session 的 ACP/evidence 文件变更。

**Architecture:** 后端 `buildSessionInspectorSnapshot()` 继续作为右侧栏 inspector 的唯一派生入口，但 `diffRows` 只使用 `buildSessionDiffRowsFromAcp(evidence, agentEvents)`。全工作区 `git status/diff` 仍保留给底部状态栏或独立 git 状态能力，不再混入右侧栏“本次会话变更”。前端保持消费 `session_inspector:snapshot` 的现有刷新路径，只补回归测试确认 snapshot 替换行为。

**Tech Stack:** Node.js、TypeScript、SQLite repo tests、React 18、Vite、node:test。

---

## Scope

### In Scope

- 保留 `buildSessionDiffRows(workspacePath)` 对真实 git 状态的独立测试，因为底部状态栏/工作区状态仍可能需要它。
- 验证 WebSocket inspector snapshot 进入前端后会替换 `diffRows`。

- 不新增复杂 diff viewer。
- 不迁移数据库。
- 不修改 ACP provider 协议。
- 不改变底部状态栏 git 信息或网络延迟实现。
- 不处理历史旧 session 缺失 ACP 结构化事件的问题。

```ts
  sessionId: string,
  evidence: SessionEvidenceEvent[],
  agentEvents: SessionAgentEvent[],

  return {
    planItems: buildSessionPlanItemsFromAcp(sessionId, evidence, agentEvents),

```

替换为：

```ts
export function buildSessionInspectorSnapshot(
  sessionId: string,
  evidence: SessionEvidenceEvent[],
  agentEvents: SessionAgentEvent[],
  _workspacePath?: string | null,
): SessionInspectorSnapshot {
  return {
    planItems: buildSessionPlanItemsFromAcp(sessionId, evidence, agentEvents),
    toolRows: buildSessionToolRows(evidence, sessionRunRepo.listBySession(sessionId)),
    diffRows: buildSessionDiffRowsFromAcp(evidence, agentEvents),
  };
}
```

Rationale: 暂时保留第四个参数，避免扩大 `session.routes.ts` 和 `session-runtime.ts` 的调用面；使用 `_workspacePath` 表明参数保留是兼容旧调用，不再参与右侧栏会话变更计算。

- [ ] **Step 2: 删除无引用 helper**

```ts
function mergeSessionDiffRows(
  eventRows: SessionDiffRow[],
  gitRows: SessionDiffRow[],
): SessionDiffRow[] {
  const rows = new Map<string, SessionDiffRow>();
  for (const row of eventRows) rows.set(row.path, row);
  for (const row of gitRows) {
    const existing = rows.get(row.path);
    rows.set(row.path, {
      path: row.path,
      status: row.status,
      additions: row.additions ?? existing?.additions ?? null,
      deletions: row.deletions ?? existing?.deletions ?? null,
      summary: row.summary ?? existing?.summary ?? null,
    });
  }
  return [...rows.values()];
}
```

## Risks

- **既有工作区脏改动风险:** 当前仓库已有多处未提交文件，执行时必须 path-specific `git add`，避免把无关改动带入 commit。
- **口径误伤风险:** `buildSessionDiffRows()` 不能删除，因为底部状态栏或其他工作区 git 状态能力仍可能使用。
- **旧 session 数据风险:** 历史会话如果没有 ACP 文件变更记录，右侧栏会显示空态；这是预期行为，不回退到 git dirty 文件。
- **刷新误判风险:** 若用户看到“没有生效”其实是 snapshot 未广播，后续执行需检查 `broadcastSessionInspectorSnapshot()` 是否在 evidence 创建后调用；当前只读定位显示事件类型和前端 reducer 已存在。
