# 全局会话提示词注入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在系统设置中新增全局会话提示词，并在 Session Workspace 每次用户消息运行前把它注入到 ACP runtime prompt 最前面，同时收敛旧房间群聊的前端可见文案。

**Architecture:** 复用现有 `settings` system scope 和 `/api/settings/system` 接口，新增 `global_session_prompt` 字段并在 `dispatchSessionUserMessage()` 的 prompt 构造链路中注入。前端沿用 `SystemSettingsDialog` 分类导航新增“会话提示词”分类，不引入新的状态库或设置接口。旧房间群聊只做前端文案收敛，后端 room/message 兼容层不删除。

**Tech Stack:** TypeScript, Node.js, Express, SQLite, React 18, TanStack Query, Vite, Tailwind, node:test.

function normalizeGlobalSessionPrompt(value: string | null | undefined): string | null {
