# 主题兼容修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让当前会话页与系统设置页兼容 Apple 亮色、Apple 暗色、Anthropic 亮色、Anthropic 暗色四种主题。

**Architecture:** 保持现有 `data-theme` 与 CSS token 架构，不重写页面结构。先补齐全局语义变量，再让会话页的 `deepsea-*` token 响应 Apple 暗色，最后用设置页局部 token 覆盖硬编码浅色。

**Tech Stack:** React 18、TypeScript、Vite、Tailwind、CSS custom properties。
