# 规划师平台技能调用实施计划

> **面向代理执行者：** 按任务逐项执行，并用复选框记录进度。

**目标：** 移除 OpenDeepSea 自有可安装/绑定 skills 系统，并在会话发送框中通过 `$` 只选择 planner 当前 ACP backend 的 platform skills。

**架构：** 保留 `/platform-skills` 作为 provider-native skills 扫描和管理层；删除 OpenDeepSea 自有 `/skills` API、UI 入口、runtime prompt 注入和相关类型引用。会话 composer 在本地 textarea 上实现 `$` picker，提交结构化 `platformSkillRefs`，后端按 session 所属项目解析 planner backend 并校验 skill 存在后，把显式 `$skill` 指令注入 planner ACP prompt。

**技术栈：** Node.js/Express/WebSocket/SQLite backend，React 18 + TypeScript frontend，node:test 单元测试，Vite build。
