# 会话入口状态保留 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让用户从其他页面返回“会话”时保留并恢复上一次选中的具体 session。

**Architecture:** 在前端新增一个小型 session workspace route memory helper。`SessionWorkspaceKeepAliveHost` 在具体 session 路由上写入记忆，`AppShell` 订阅记忆并把顶部“会话”链接指向最后 session 路径。

**Tech Stack:** React 18、React Router、TypeScript、node:test、localStorage。
