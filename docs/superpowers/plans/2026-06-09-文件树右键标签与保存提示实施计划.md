# 文件树右键、标签页密度与保存提示 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复会话文件浏览器中文件树整行右键响应，收紧文件 tab 标签页密度，并在文件保存成功后显示 toast。

**Architecture:** 前端保持现有 `FileBrowserWorkspace` 协调模式。`WorkspaceFileTree` 通过容器级右键事件委托解析当前 entry，`session-os.css` 收紧 FlexLayout tab 覆盖样式，`FileBrowserWorkspace.saveFile()` 在真实保存成功后触发 `sonner` toast。

**Tech Stack:** React 18、TypeScript、react-complex-tree、FlexLayout、sonner、Tailwind/CSS、Vite。

## Task 1: 修复文件树整行右键菜单

**Files:**
- Modify: `packages/frontend/src/session-ui/WorkspaceFileTree.tsx`
- Modify: `packages/frontend/src/session-ui/session-os.css`

- [x] **Step 1: 增加 entry 解析与容器级右键 handler**

在 `WorkspaceFileTree` 中新增 `openContextMenuForEntry` 和 `handleTreeContextMenu`：

```tsx
  const openContextMenuForEntry = useCallback((entry: WorkspaceDirectoryEntry, event: React.MouseEvent) => {
    event.preventDefault();
    event.stopPropagation();
    onSelectEntry(entry);
    setContextMenu({ x: event.clientX, y: event.clientY, entry });
  }, [onSelectEntry]);

  const handleTreeContextMenu = useCallback((event: React.MouseEvent<HTMLDivElement>) => {
    const target = event.target instanceof Element ? event.target : null;
    const titleElement = target?.closest<HTMLElement>('[data-workspace-entry-path]');
    if (!titleElement) return;

    const entryPath = titleElement.dataset.workspaceEntryPath ?? '';
    const entry = visibleTreeItems[entryPath]?.data;
    if (!entry) return;

    openContextMenuForEntry(entry, event);
  }, [openContextMenuForEntry, visibleTreeItems]);
```

- [x] **Step 2: 将 handler 绑定到文件树外层**

把文件树根节点改为：

```tsx
    <div
      ref={treeRef}
      className="deepsea-workspace-tree"
      onContextMenu={handleTreeContextMenu}
    >
```

- [x] **Step 3: 调整 `WorkspaceTreeTitle` 参数**

移除 `onContextMenu` prop，标题节点只保留数据标记：
