# 会话消息粘贴附件与项目文件库上传 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 会话页原生 textarea 消息框支持粘贴图片和文本文件、发送前预览，发送后文件上传到项目文件库，并随 session 消息展示和注入 agent 上下文。

**Architecture:** 前端在 composer 内维护待发送附件队列，发送前调用现有 `POST /projects/:projectId/files` 上传到项目文件库，拿到 `ProjectFile.id` 后通过 `libraryFileRefs` 随 `session.message.send` 发送。后端复用项目文件库记录，在 session message metadata 中写入 `attachments` 和 `library_file_refs`，并让 `buildSessionFileReferenceContext` 对上传文本文件注入内容、对上传图片传递本地 `imagePaths`。

**Tech Stack:** React 18、TypeScript、Vite、Express、WebSocket、SQLite、node:test、现有 `fileRepo`、`ProjectFilePreviewDialog`、`MessageContent`。
