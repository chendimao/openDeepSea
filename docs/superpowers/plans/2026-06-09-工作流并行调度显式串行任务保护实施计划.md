# 工作流并行调度显式串行任务保护 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 防止 graph workflow 在已有 implementation 子任务 active run 时，通过单 child fallback 启动 `workflowPlan.tasks[*].mode === 'serial'` 的 sibling。

**Architecture:** 保留并行 batch 只选择 `mode: parallel` 的既有逻辑；在 `selectNextImplementationChild()` 的 fallback 选择中增加显式 serial 保护：只要存在 active implementation writes/runs，serial 子任务必须等待。这样 active parallel sibling 仍可续跑，但用户/Coordinator 标记为 serial 的任务不会与任何 running implementation 子任务重叠。

**Tech Stack:** Node.js、TypeScript、SQLite/better-sqlite3、node:test。
