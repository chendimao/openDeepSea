# 会话变更按当前会话统计修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复会话页右侧栏「本次会话变更」没有按当前 session 生效的问题，使其只展示当前会话 ACP 事件产生的文件变更，并在相关变更事件到达时刷新。

**Architecture:** 后端 `SessionInspectorSnapshot.diffRows` 只从当前 session 的 evidence 和 agent events 派生，不再混入 live git 工作区全局变更。前端刷新判定补齐嵌套 ACP `apply_patch` / `edit` 工具事件，确保当前 session 产生文件修改后会重新请求 workspace snapshot。底部状态栏 Git 信息继续走原有 `status.git.changedFileCount` 路径，不纳入右侧栏 session changes。

**Tech Stack:** TypeScript, Node.js `node:test`, React 18, Vite, WebSocket session events.

---

## Scope

本计划只修复右侧 Inspector 的「本次会话变更」统计与刷新，不改变底部状态栏 Git changed 统计，不改变消息流、运行状态、计划项或工具调用的展示结构。

已确认当前知识库 scope 对「右侧栏 本次会话变更」无可引用结果；规划依据来自仓库代码和既有设计文档。当前工作区已有多处未提交改动，执行智能体不得回滚或纳入无关文件。

- [ ] **Step 3: 实现嵌套 payload 候选扫描**

在 `packages/frontend/src/pages/SessionWorkspacePage.tsx` 中用以下实现替换 `isSessionChangeEvidence()`，并新增 `sessionChangePayloadCandidates()`：

```ts
function isSessionChangeEvidence(event: Extract<WsServerEvent, { type: 'session_evidence:new' }>['event']): boolean {
  for (const candidate of sessionChangePayloadCandidates(event.payload)) {
    const toolName = firstString(candidate.name, candidate.toolName, candidate.tool_name);
    if (toolName && /^(edit|multiedit|patch|apply_patch)$/i.test(toolName)) return true;
    const rawType = firstString(candidate.rawType, candidate.type, candidate.event_type);
    if (rawType && /file_diff|patch|diff/i.test(rawType)) return true;
  }
  return event.event_type === 'file_diff';
}

function sessionChangePayloadCandidates(payload: Record<string, unknown>): Record<string, unknown>[] {
  const event = record(payload.event);
  const eventPayload = record(event?.payload);
  const nestedPayload = record(payload.payload);
  const rawEvent = record(payload.rawEvent);
  const rawParams = record(rawEvent?.params);
  const rawUpdate = record(rawParams?.update) ?? record(rawEvent?.update);
  const rawUpdatePayload = record(rawUpdate?.payload);
  return [
    payload,
    event,
    eventPayload,
    nestedPayload,
    rawEvent,
    rawUpdate,
    rawUpdatePayload,
  ].filter((value): value is Record<string, unknown> => Boolean(value));
}
```

保留文件中已有的 `record()` 和 `firstString()` helper，不新增跨文件工具。

## Risks

- `buildSessionInspectorSnapshot()` 当前仍保留 `workspacePath` 参数以降低调用面变更；后续若确认无外部调用依赖，可单独清理签名。
- 如果 ACP provider 产生的文件变更事件使用新的 payload 形态，前端刷新判定可能还需要继续补候选路径；本计划已覆盖常见 `payload.event.payload` 和 `rawEvent.params.update`。
- 右侧栏不再展示 live git 工作区未提交文件后，用户仍可从底部 Git 状态看到全局 changed count；这是刻意分离 session 级和 workspace 级信号。
