# 会话底部状态栏 Git 信息 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在会话页底部状态栏路径区域显示当前项目的本地 Git 分支与工作区状态。

**Architecture:** 复用现有 `SessionWorkspacePayload.status.git`，只在前端 `BottomStatusBar` 内派生显示文案并追加到路径区域。实现不修改后端、共享类型或 WebSocket contract，CSS 只负责保持 chip 可截断、低干扰且不增加底部栏高度。

**Tech Stack:** React 18, TypeScript, lucide-react, CSS, Node.js `node:test`, `tsx`, Vite build。

---

## 范围与并行判断

本次改动集中在 `SessionShellView.tsx`、`session-os-system.css` 和 `SessionShell.test.tsx`。这些文件会在同一个 UI 单元内连续修改，不适合拆成多个并行子任务；并行写入会增加同文件冲突与测试夹具返工风险。执行时采用单线程、测试先行。

- [x] **Step 1: 在 `BottomStatusBar` 前新增格式化函数**

在 `isSessionInspectorVisibleForWorkspacePane` 后、`BottomStatusBar` 前插入：

```tsx
type BottomGitState = 'clean' | 'changed' | 'conflicts';

function formatBottomGitBranch(branchName: string | null): string {
  const normalized = branchName?.trim();
  return normalized ? normalized : 'detached';
}

function formatBottomGitState(git: StatusSnapshot['git']): { label: string; state: BottomGitState } {
  if (git.conflictRisk === 'high') return { label: 'conflicts', state: 'conflicts' };
  if (git.changedFileCount > 0) return { label: `${git.changedFileCount} changed`, state: 'changed' };
  return { label: 'clean', state: 'clean' };
}
```
