# 会话工作流先分析再展示 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让会话聊天区先展示 planner 分析正文，再展示 workflow 流程卡片。

**Architecture:** 后端将 workflow intake 的公开阶段从 planning 调整为 analysis。前端把 workflow 控制事件与 assistant agent_stream 正文分离，避免分析正文被 workflow 卡片合并隐藏。

**Tech Stack:** TypeScript, Node test runner, React 18, Vite, server-side render tests.
